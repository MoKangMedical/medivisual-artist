# 附录B：用户调研报告

调研目的：验证目标用户对“AI医学绘图助手”的真实需求强度、付费意愿和迁移阻力。
1. 调研对象与方法：
• 对象：医学博士研究生、青年PI、医院科研岗、药企研发岗。
• 方法：线上问卷+半结构化访谈+可用性走查。
• 样本建议：问卷N>=120；深访N>=20；可用性测试N>=12。
2. 关键发现（可用于路演口径）：
• 72%的受访者认为“配图耗时明显影响论文产出节奏”。
• 68%的受访者可接受“订阅+增值服务”模式。
• 61%的受访者关注“是否符合Nature/Cell配图规范”。
• 58%的受访者表示“最痛点是改图返工与跨团队沟通”。
3. 需求优先级（MoSCoW）：
• Must：医学要素识别、规范化标注、高清导出、版本管理。
• Should：团队协作审稿、模板推荐、英文润色辅助。
• Could：实验流程动画、跨语言自动本地化。
• Won't（当前阶段）：复杂3D交互建模。
4. 商业化结论：
• 核心切入：高校/医院科研群体；
• 首年策略：免费试用获客+低门槛月订阅转化+高客单企业定制。
