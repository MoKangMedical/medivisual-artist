# 附录C：技术架构文档

目标：说明系统可行性、可扩展性与安全边界，降低投资方的技术不确定性。
1. 总体架构（逻辑分层）：
• 接入层：Web端/管理后台/API网关。
• 应用层：任务编排、提示词引擎、模板服务、审校规则引擎。
• 模型层：通用LLM（语义理解）+图像生成模型（视觉渲染）+医学知识检索。
• 数据层：用户数据、模板库、任务日志、审计日志、对象存储。
2. 核心流程：
• 输入科研摘要→解析医学实体与关系→生成结构化提示词→图像生成→规则审校→导出。
3. 关键技术选型：
• 语义引擎：GPT-4/Claude类模型；
• 图像生成：即梦（Volcano Engine）及可替换模型适配层；
• 服务架构：模块化微服务+消息队列（异步任务）；
• 可观测性：日志、指标、告警三位一体。
4. 安全与合规控制：
• 传输加密、存储加密、最小权限、操作审计；
• 数据分级与脱敏策略；
• 模型输出内容风控（术语误导、版权冲突、医学不当表达）。
