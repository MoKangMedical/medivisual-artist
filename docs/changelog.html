v1.0.0 2026-04-28

正式发布

MediVisual Artist 首个正式版本发布。基于深度医学语义理解的AI引擎，支持从文字描述到出版级医学插图的端到端生成。集成DALL-E 3 API，实现3种专业输出风格（学术期刊、教学课件、科普展示），并内置期刊合规审查模块，确保输出满足 Nature、Lancet、NEJM 等顶级期刊的配图规范。

AI医学插图生成 3种输出风格 期刊合规审查 DALL-E 3集成Demo
v0.9.0 2026-04-20

Beta 测试

开启内测用户邀请计划，面向国内医学院校、三甲医院科研团队及生命科学领域的研究者开放Beta测试。通过大规模用户调研与深度访谈，深入了解医学研究者在可视化创作中的核心痛点与工作流程需求，为产品定型提供关键数据支撑。

内测用户邀请 120+用户调研 20+深度访谈
v0.8.0 2026-04-10

Alpha 版本

核心AI引擎搭建完成，实现从医学文本到可视化图像的4阶段管线原型：语义解析 → 结构识别 → 布局规划 → 图像生成。完成医学术语理解、解剖结构识别、空间关系推理等关键技术模块的原型验证，为后续产品化奠定技术基础。

核心AI引擎搭建 4阶段管线原型
v0.7.0 2026-03-25

项目启动

MediVisual Artist 项目正式立项。组建创始团队，完成医学可视化市场调研，分析国内外竞品格局。基于调研结果制定产品路线图，明确"AI驱动、期刊合规、2小时交付"三大核心差异化方向，确定首期技术选型与产品规划。
