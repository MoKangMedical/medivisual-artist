传统医学插图需要2-3天，严重影响论文产出节奏。72%的研究者表示这是最大的瓶颈。

58%的研究者将修改返工和跨团队沟通列为首要痛点。每轮修改都意味着额外的时间和费用。

61%的研究者关注Nature/Cell等顶刊的格式合规性。不合规的插图直接导致退稿或延迟。

外包成本高昂

专业医学插画师报价高、排期长。年轻PI和博士生难以负担，且无法保证最终效果。
